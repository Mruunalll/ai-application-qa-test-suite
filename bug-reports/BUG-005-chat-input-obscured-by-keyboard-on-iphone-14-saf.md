## BUG-005 — Chat input obscured by keyboard on iPhone 14 Safari (mobile web)

**Title:** Chat input obscured by keyboard on iPhone 14 Safari (mobile web)
**Environment:** iPhone 14, iOS 17.4, Safari (mobile web — not native app)
**Severity:** Critical | **Priority:** High

**Steps to Reproduce:**
1. Go to chat.openai.com on Safari iPhone 14
2. Tap the message input field
3. iOS keyboard slides up

**Expected Result:** Input field scrolls up with keyboard; send button visible above keyboard
**Actual Result:** Input field and send button hidden completely behind keyboard; user cannot see what they're typing or tap Send
